数据管理

数据仅保存在当前浏览器的本地存储中，不会上传到任何服务器，建议定期导出备份。

云端同步

把数据存到你的 GitHub Gist，换设备或换浏览器时下载回来，就能保持同一份记录。

未连接

令牌只保存在你自己的浏览器本地，不会发送给除 GitHub 以外的任何人。建议创建令牌时只勾选 Gist 权限，并设置较短有效期；不用时可以点“清除令牌”。
